# A terminal portfolio

The website still exists. This is the same sections — home, projects,
experience, stack, notes — just rendered in a terminal you can open
locally or over SSH.

## Why

I already ship TUIs. Putting the portfolio in one means the work and
the resume live in the same place. Open it, poke around, leave. No
browser chrome.

## What is here

- **Home** — who I am and how to reach me
- **Projects** — things I have shipped
- **Experience** — roles, kept short
- **Stack** — tools, grouped
- **Blogs** — notes like this one

Try it:

```bash
# from anywhere
ssh "ash@tuis.ashutoshbind.com"
```

Posts start as markdown here, then get adapted for the site when they
are worth keeping. More soon.
